# Умная теплица

Информационная система для выращивания салатов и зелени в домашней мини-теплице.
Плата Arduino Uno измеряет влажность почвы, освещённость, температуру и влажность воздуха,
уровень воды в баке и передаёт пакеты на компьютер. Программа на компьютере принимает пакеты,
проверяет контрольную сумму, накапливает их в буфере, выполняет дискретизацию и сглаживание.

Проект выполняется по лабораторным работам дисциплины
«Программное и аппаратное обеспечение информационных систем»:

| Работа | Содержание |
|--------|------------|
| ЛР 1 | Проектирование: требования, структурная схема, UML-диаграммы |
| ЛР 2 | Программная часть: приём данных, буфер, дискретизация, сглаживание EMA |
| ЛР 3 | Аппаратная часть: программа платы Arduino, приём по COM-порту |
| ЛР 4 | Хранение и защита данных: PostgreSQL, шифрование |

## Структура

```
server/                               сервер: Java 17, Spring Boot
  build.gradle, settings.gradle       сборка Gradle
  gradlew, gradlew.bat, gradle/       обёртка Gradle
  .env.example                        образец файла с логином и паролем
  test-data/packets.log               журнал тестовых пакетов
  src/main/resources/application.yml  настройки
  src/main/java/ru/greenhouse/server/
    device/       приём и разбор пакетов
    processing/   буфер, дискретизация, EMA
    service/      сервис теплицы, аутентификация
    web/          REST API
    report/       вывод в консоль, CSV и графики
  src/test/java/...                   автоматические тесты JUnit 5
android/                              мобильное приложение: Kotlin, Jetpack Compose
  app/src/main/java/ru/greenhouse/app/
    data/         запросы к API (Retrofit)
    ui/           экраны и модель представления
```

## Запуск сервера

Нужна Java 17 или 21. В каталоге `server` скопировать `.env.example` в `.env` и задать пароль `GH_PASSWORD`.

```
cd server
./gradlew test       # тесты
./gradlew bootRun    # сервер на порту 8080
```

В Windows вместо `./gradlew` можно использовать `gradlew.bat`. Сервер воспроизводит журнал
`test-data/packets.log` в 10 раз быстрее реального времени, без пауз:
`./gradlew bootRun --args="--greenhouse.speed=0"`. После приёма журнала в `server/results`
сохраняются таблица `samples.csv` и графики `*.png`.

## Мобильное приложение

Открыть каталог `android` в Android Studio и запустить на телефоне или эмуляторе.
На экране входа указать адрес сервера: `http://IP_компьютера:8080/` (телефон в той же сети Wi-Fi)
или `http://10.0.2.2:8080/` (эмулятор), логин `admin` и пароль из `server/.env`.

## REST API

| Метод | Адрес | Назначение |
|-------|-------|------------|
| POST | /api/login | вход, ответ — токен |
| POST | /api/logout | выход |
| GET | /api/current | последний отсчёт и состояние теплицы |
| GET | /api/samples?sensor=soil&minutes=30 | ряд для графика |
| GET | /api/stats | статистика |
| GET | /api/events | журнал событий |

Все запросы, кроме входа, передают заголовок `Authorization: Bearer <токен>`.

## Формат пакета

```
$GH,номер,почва,свет,температура,влажность,насос,лента,вода,режим_света,часы*XX
$EV,PUMP,1,A,3*48
```

`XX` — исключающее ИЛИ (XOR) кодов всех символов между `$` и `*` в шестнадцатеричном виде.
